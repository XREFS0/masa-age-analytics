# MASA Age Analytics

A chronological lifespan calculation suite engineered in Python and CustomTkinter, providing exact day-month-year metrics and total elapsed hourly lifespan computations.

## Technical Architecture

The codebase follows modular software engineering patterns and OOP structure, designed for reliability, high maintainability, and clean separation of concerns:

- **Component Layering**: User interface and computational state are decoupled into specialized controllers and event loops.
- **Defensive Engineering**: Comprehensive validation guards protect against malformed inputs and runtime exceptions.
- **Modern Design Tokens**: Designed with a high-contrast dark aesthetic adhering to modern developer tooling visual standards.

## Features

- Precise calendar math resolving leap year variations and variable month durations.
- Granular lifespan metrics including total days and approximate elapsed hours.
- Input boundary verification preventing erroneous future-date computations.
- Modular desktop interface styled with CustomTkinter Dark Theme.

## Prerequisites

- Python 3.10 or higher
- Required packages:

```bash
pip install customtkinter
```

## Execution

Initialize and run the module via the command line:

```bash
python "Simple Accurate Age Calculator App using Python/index.py"
```
